# Seven-Minute CORTEX Review Walkthrough

## 1. Position the product — 30 seconds

“CORTEX is an enterprise AI Mission Control platform. Customer complaint intelligence is the demonstration mission, while the architecture is reusable across compliance, incidents, contracts and research.”

## 2. System Status — 30 seconds

Show PostgreSQL, Azure OpenAI, ChromaDB and persistent LangGraph state as ready.

## 3. Mission creation — 45 seconds

Use the prepared objective, keep the synthetic complaint dataset selected and start execution.

## 4. Workflow Monitor — 90 seconds

Explain:

- Azure creates the plan.
- CORTEX routes tasks using Agent Passports.
- Knowledge Retrieval and Complaint Intelligence execute in parallel.
- Failed agent calls retry automatically.
- Each node stores tokens, latency, output and audit data.

## 5. Approval Centre — 60 seconds

Show that production rollback or another high-impact recommendation pauses the graph. Approve it as Reviewer and show the same workflow thread resume.

## 6. TrustGraph — 60 seconds

Open a verified claim and show its supporting incident, release and complaint evidence. Explain groundedness and hallucination risk.

## 7. Executive Report — 60 seconds

Highlight:

- Verified findings only
- Confirmed/probable/unverified root causes
- Prioritised actions
- Governance status
- Mission Success Score
- Next recommended action

## 8. ShadowBench and audit — 45 seconds

Run an isolated replay. Explain that shadow output never changes the approved report. Finish with the audit log.

## Closing line

“CORTEX does not merely generate an answer; it proves how the answer was created, why it can be trusted, and where a human must remain in control.”
